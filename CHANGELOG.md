# Changelog

All notable changes to Tertius will be documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 0.1.0 - 2026-08-16

### Added

- Local microphone capture and Parakeet ONNX transcription.
- Global hold-to-talk and toggle activation.
- Automatic insertion with persistent clipboard fallback.
- Floating, movable voice widget with live audio and processing feedback.
- Deterministic spoken formatting and lightweight application-category cleanup.
- Three-day local transcript history with automatic pruning and copy controls.
- Native tray lifecycle and single-instance behavior.
- Verified speech-model downloads using a pinned byte count and SHA-256.
